# 📁 File Manager Project

A simple command-line File Manager built using Python.

This project was created while learning Python File Handling, Exception Handling, Functions, Loops, and the `pathlib` module.

---

## 🚀 Features

* Create a file
* Read file content
* Update file

  * Rename file
  * Overwrite existing content
  * Append new content
* Delete a file
* Display available files and folders
* Exception handling for invalid operations
* Menu-driven interface

---

## 🛠 Technologies Used

* Python 3
* pathlib
* File Handling
* Exception Handling
